# WCGroups 微信分组

独立的微信首页会话分组插件，支持内置分类和自定义分组。

- 好友、群聊、其他、全部和即时消息分类。
- 自定义分组，支持添加、重命名、排序、删除和成员管理。
- 联系人选择显示头像，好友与群聊分区并支持搜索。
- 未读数字和红点，支持角标样式、颜色及位置设置。
- 下划线或滑块指示，支持字体、颜色及动画调节。
- 横滑切换分组，可设置循环、方向与震感。
- 即时消息按账号保存，支持阅后移出。
- 置顶会话持续显示，以及分组栏、置顶和设备横幅统一改色。

设置入口位于插件管理，未安装插件管理时显示在微信“我”页面。主页分组默认关闭，支持浅色与深色外观。与 WCRound 同时使用时，分组栏适配首页圆角。

支持 JSON 配置导入与导出，设置界面采用圆角卡片和分组折叠。
